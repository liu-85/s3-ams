# v1.1.18 —— 退料时间改为 4 秒 + WEB 可调

**版本号**：`1.1.18-s3ams`
**基于**：v1.1.17
**编译**：RAM 23.3% (76252 B) / Flash 40.3% (1215788 B)

---

## 一、这次改了什么

自动换料（换色）时的**退料超时**从 **7 秒**改为 **4 秒**，并且在 WEB 上新增了可调设置。

> 说明：v1.1.17 那个「离合没吸合彻底就给电机」的改动**保留在本版里**。
> 后来确认现场真正的根因是**电机减速箱打齿**（换电机后正常），
> 但「等离合机械稳定后再加载」本身是合理的保护，减少离合磨损，所以没有回退。
> 直接刷 v1.1.18 即可，不必再单独刷 v1.1.17。

---

## 二、退料时间是什么

`PULLBACK_TIMEOUT[]`：打印机换色时，本设备**退旧料允许的最长时间**（单位秒）。
到时间就停止退料、清 latch，避免一直空转。

- 改之前：默认 **7 秒**
- 改之后：默认 **4 秒**

它**只作用于自动换料退料**，**不影响**「手动点动」的时长（点动时长在「手动点动」卡片独立设置）。

---

## 三、WEB 新设置

新增「**退料时间**」卡片（在「手动点动」和「电机电流采样」之间）：

| 项 | 值 |
|---|---|
| 输入框 | `pullback_seconds`，单位秒 |
| 范围 | **3 ~ 30 秒** |
| 默认值 | **4** |
| 保存按钮 | 「保存退料时间」 |
| 后端接口 | `POST /pullback_set {"sec": 4}` |
| 生效方式 | **立即生效**，不用重启 |
| 持久化 | NVS（`settings_storage`，掉电保留） |
| 回显 | `/status` 新增 `pullback_sec` 字段 |

本硬件是**单电机 + 8 离合**，所以这是一个**全局值**，保存时会统一写 16 路。

### 怎么调

- 换色时**旧料还没退干净电机就停了** → 调**大**
- **退到位后还在空转**等超时 → 调**小**（能明显缩短换色等待）

## 五、⚠️ 重要：页面上有两个「退料」相关卡片，别搞混

| 卡片 | 后端接口 | 是否生效 |
|---|---|---|
| **退料时间**（本次新增） | `/pullback_set` | ✅ **真正生效**，控制换色退料超时 |
| **退料参数**（连续退料/蠕动退料，很早就有） | `/retract_set` | ❌ **不生效**，后端是 `handle_ok` 空占位 |

「退料参数」那张卡是从 `esp32s3-485`（C3 降级 / MQTT 方案）继承来的遗留 UI，
本固件走 RS-485 BambuBus，**用不到那套参数**，它的保存按钮点了也不会有任何效果。
**要调退料时长，请用本次新增的「退料时间」卡片。**

## 七、验证

1. 打开 WEB，确认版本号显示 `1.1.18-s3ams`
2. 找到「**退料时间**」卡片，输入框应显示 **4**
3. 改成别的数（如 6）点保存 → 提示「退料时间已保存（所有通道统一）」，输入框保持 6
4. **重启设备**再打开页面 → 仍显示 6（说明已持久化到 NVS）
5. 触发一次换色，观察退料是否在设定时间内结束

## 八、遗留

- 退料超时是「**到时强制停**」，不是「**退到位自动停**」。
  真正理想的是靠挤出机信号判断退完，但本机没有可靠的到位反馈，仍是时间兜底。
- 如果 4 秒对你仍然偏长或偏短，直接在 WEB 上调即可，不用重新编译。
