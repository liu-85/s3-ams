# v1.1.22 —— 修 v1.1.21 引入的 `[0500-40A3]` AMS A 通信异常

## 一句话

v1.1.21 把 `0x402` 序列号包的"越界台号"处理从 **clamp 到 0** 改成了
**直接 return 不应答**。结果打印机问 AMS-A 要序列号时可能一个包都收不到，
直接弹 `[0500-40A3] AMS(或AMS lite) A 通信异常`。本版回退这一处（连同
`0x06` 的 return、22 字节版本包），**恢复 1.1.20 的应答行为**。

---

## 现场症状

刷 1.1.21 后，打印机立即弹窗：

```
AMS(或AMS lite) A 通信异常，请拔插模块连接线或重启打印机。
[0500-40A3 171631]
```

1.1.20 及以前正常（能打印，只是耗材页有重复 AMS 卡片）。

---

## 根因

`send_for_long_packge_version()` 的 `0x402` 分支：

```cpp
// 1.1.20（正常）
AMS_num = printer_data_long.datas[33];
if (AMS_num >= AMS_COUNT) AMS_num = 0;   // clamp，照样应答

// 1.1.21（报错）
if (printer_data_long.data_length > 33) AMS_num = datas[33];
else if (data_length > 0)              AMS_num = datas[0];
if (AMS_num >= AMS_COUNT) return;        // ← 不应答
```

关键点：**0x402 的台号不一定在 `payload[33]`**。
包长 ≤ 33 时会退到 `payload[0]` 兜底，而 `payload[0]` 不一定是台号
（可能是别的字段）。值一旦 ≥ `AMS_COUNT`（=2），就 `return` →
打印机拿不到序列号包 → 判定通信异常 → 拒绝打印。

参考实现 `esp32s3-485/main/comm_485.c` 的 `on_version()` 同样有 `pl[0]` 兜底，
但紧接着是：

```c
if (unit >= AMS_UNITS) unit = 0;    /* clamp，不是 return */
```

**这是我 1.1.21 偏离参考的地方。**

同样的错误还有 `0x06` 握手：参考实现对它**无条件回包**，我加了
`if (req_num >= AMS_COUNT) return;`。0x06 是打印机逐台握手帧，
少回一次同样会被记成通信异常。

---

## 改动（三处回退）

| 位置 | 1.1.21 | 1.1.22 |
|---|---|---|
| `0x402` 越界台号 | `return` 不应答 | `AMS_num = 0` 继续应答 |
| `0x06` 握手台号越界 | `return` 不应答 | 撤销检查，无条件回包 |
| `0x103` 版本包长度 | 22 字节，`[20]`/`[21]` 都写 | **21 字节**，只写 `[20]` |

---

## 保留 1.1.21 的改动

- `AMS_COUNT = 2`（`MAX_AMS_COUNT` / `DEFAULT_AMS_COUNT`）
  —— 符合参考实现 `BOARD_CHANNEL_COUNT / 4` = 8/4 = 2
- `BambuBus_init()`：`statu = (a < AMS_COUNT) ? online : offline`
  —— 幽灵 AMS-C/D 报 offline，不参与 0x05 注册
- `0x402` 读 `datas[33]` 前先查 `data_length > 33`（防越界读，与参考一致）

---

## 设计原则（写下来避免再犯）

> 链路上宁可多回一个"台 0 的序列号"（最多耗材页多张卡片，**不影响打印**），
> 也绝不能让任何一次查询出现**无应答** —— 无应答直接等于通信异常，
> 打印机会拒绝工作。

"越界就不应答"只在**短包**（0x05/0x21A/0x211）里成立，因为那是主动上报，
不回只是少一台；**长包的查询-应答对（0x402/0x103/0x06）必须每次都回**。

## 烧写

```bash
python flash_s3.py COM6
```

或网页 OTA 上传 `firmware.bin`。

**刷完必须拔插 485 线或重启打印机重新枚举**，否则打印机仍用缓存的旧设备表。

---

## 验证要点

1. 开机后不再弹 `[0500-40A3]`（这是本版核心目标）
2. 耗材页应只有 AMS-A / AMS-B（若仍有幽灵卡片，说明是打印机侧缓存的
   旧设备列表，需要在打印机上"移除 AMS"后重新枚举）
3. 进料 / 退料 / 打印中换色 全部照旧
